# Política de seguridad

Tribunal Agents es una demo experimental para uso local. El tribunal solicita el modo de solo lectura de los CLI y depende del aislamiento que ofrezca cada uno. El visor web está pensado para ejecutarse en `127.0.0.1`.

## Reportar una vulnerabilidad

Envía el reporte mediante el [formulario privado de GitHub](https://github.com/RobertC1006/tribunal-agents/security/advisories/new). Incluye la versión o el commit, el sistema operativo, el comportamiento observado y su impacto. Usa datos de prueba y omite credenciales, código privado y actas con datos sensibles.

Consulta [privacidad, seguridad y costes](README.md#privacidad-seguridad-y-costes) para conocer el alcance de la demo.
